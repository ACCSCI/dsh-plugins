ACCSCI 的 DSH 插件

面向 DeepSeek Harness（dsh）的插件：host 半 + 浏览器半，按提交从本仓库安装。

把它加进 DSH

  1. 打开插件，在实验性插件下打开自定义插件索引。
  2. 切到发现，点添加索引源，粘贴下面的地址。
  3. 选择插件并安装；确认框会显示 git 仓库、提交和目录。
https://accsci.github.io/dsh-plugins/index.json

索引里的插件

自动重试 Auto retry

供应商临时故障（超时、断流、限流、5xx）时把模型请求重试到成功；额度、鉴权、请求非法则立即失败。开关在设置与会话头药丸，两处同步。

Retry transient provider failures until they succeed, from a GUI switch that never retries quota or credential errors.

@accsci/dsh-auto-retry · v1.0.0 · 源码

系统监控 System monitor

输入框下方的 CPU / 内存 / GPU 实时读数：CPU 与内存取自 node:os，全平台可用；GPU 走 Windows 性能计数器，其他平台显示为不可用。

Live CPU, memory and GPU readout under the DSH composer.

@accsci/dsh-sysmon · v1.0.0 · 源码

工作区待办 Workspace todo

绑定到当前会话工作目录的待办清单：会话顶栏一个按钮打开浮层面板；数据存在 <工作目录>/.dsh/todos.json，同一目录下的所有会话共享一份。

A todo list bound to the Session's working directory, opened from the Session header.

@accsci/dsh-workspace-todo · v0.1.0 · 源码

索引是第三方内容：标题、图标和来源都由本仓库声明，DSH 只校验文件格式。本仓库同时提供 改过的源码，按目录安装这条路一直可用。
