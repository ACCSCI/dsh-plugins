# 任务通知 · Task Notifier

任务完成、出错时提醒你;右上角铃铛打开**通知中心**(类似手机通知列表)。

## 能力

| 能力 | 说明 |
| --- | --- |
| 三个提醒通道 | 右下角浮层 + 提示音 + 桌面通知(授权后) |
| 通知中心 | 铃铛打开列表:未读角标、单条已读、全部已读、一键清空 |
| **按工作区分组** | 每个工作区一个分组头(名称 + 条数),点击整组折叠/展开 |
| **最后一条助手回复** | 通知里附带任务产出摘要(最多 220 字,列表显示 2 行) |
| **免打扰时段** | 面板底部开关 + 起止时间;时段内只记录、不弹浮层/不响铃/不弹桌面通知,支持跨午夜 |
| 点击跳转 | **通知列表**、**浮层**、**桌面通知**点击都直接打开对应会话,并当场标记已读;应用在其他窗口后面时,桌面通知点击会先由 Host 把窗口恢复到前台再跳转 |`n| **访问即已读** | 切到某个会话(不管从哪进)时,该会话的历史通知自动变已读;正在看的会话产生新通知时直接就是已读 |
| 归属信息 | 显示**工作区名 / 会话标题**(标题不可用时退化为目录名) |
| 持久化 | 列表与免打扰设置存 `localStorage`,刷新、重开页面后仍在 |
| 补发 | 通知发生在页面关闭/刷新期间时,启动后补发最近 10 分钟内最多 3 条 |
| 静默去重 | 同一事件不会因重新轮询而重复提醒;同一会话 4 秒内的同类型提醒合并 |

## 触发时机

- `api-session/status` → 会话由运行转为空闲:**任务已完成**(附助手回复摘要)
- `api-session/error` → 会话出错:**任务出错**(8 秒内与该会话的完成事件合并,只报一次)

## 结构

```
index.js           Host 半侧:订阅会话事件,解析标题/工作区/摘要,开 /plugins/dsh-notifier/feed 长轮询端点
client.js          Client 半侧:页头铃铛 + 通知中心(分组/已读/清空/免打扰) + 浮层
cordis.patch.yml   插入插件行
locale/*.json      插件管理中显示的标题/描述
```

Host 侧解析 `ctx.sessionTitle`、`ctx.workspaceRegistry` 和会话日志里的最后一条助手消息,
随事件一起下发;Client 只负责渲染,所以切换语言后历史通知的文案也会跟着变。

## 端点

`GET /plugins/dsh-notifier/feed?after=<seq>&wait=<ms>` — 长轮询,有新事件立即返回。
`after=0&wait=0` 用于首次拉取。端点只监听 127.0.0.1。`p=open-ok|open-fail` 是跳转诊断:点通知时回写一次,`.debug/host.log` 里能查到服务是否可用、调用的会话 id 和异常。
